## ✨ Por que usar o Tekky Certificados?

Gerenciar certificados pelo Windows (certlm.msc) é complexo e visualmente datado. O Tekky traz:
1. **Interface Moderna:** Estilo *Glassmorphism* com modo escuro nativo.
2. **Inteligência de Vencimento:** Alertas visuais antes do certificado expirar.
3. **Segurança de Dados:** O software roda localmente. Suas chaves privadas nunca saem do seu PC.

## 🚀 Funcionalidades

### 🔹 Versão Gratuita (Vitalícia)
*   **Painel de Monitoramento:** Visualize todos os certificados (CurrentUser e LocalMachine) em uma única tela.
*   **Busca Instantânea:** Filtre centenas de certificados por nome ou CNPJ em milissegundos.
*   **Status de Saúde:** Alertas automáticos para certificados vencidos ou a vencer em 30 dias.

### ⭐ Versão PRO (Assinatura Mensal/Anual)
*   **💾 Backup de Segurança (A1):** Exporte certificados A1 para arquivos `.pfx` com senha de forma ultra rápida.
*   **🗑️ Limpeza de Sistema:** Exclua certificados antigos que poluem a lista de seleção do Chrome/Windows.
*   **🔄 Update Center:** Atualizações automáticas silenciosas para garantir compatibilidade com novas builds do Windows.
*   **📞 Suporte VIP:** Acesso direto aos desenvolvedores via WhatsApp para resolução de problemas técnicos.

## 📥 Instalação Rápida

1.  Baixe o instalador na página de [Releases](https://github.com/tekkydev/tekky-certificados/releases/latest).
2.  Execute o `Tekky.Certificados.Setup.exe`.
3.  Ao abrir, preencha seu Nome, E-mail e WhatsApp para ativar seu **Trial de 7 dias**.
4.  Pronto! Suas funções PRO estarão liberadas instantaneamente.

## 🛠️ Stack Tecnológica

*   **Frontend:** Electron.js (HTML5, CSS3 moderno, Vanilla JS).
*   **Backend:** Node.js integrado com **PowerShell Core** para manipulação segura da *Windows Certificate Store*.
*   **Segurança:** Criptografia SHA256 para geração de ID de máquina exclusivo.
*   **API:** Integração com backend PHP 8/MySQL para gestão de licenças em tempo real.
